# LearnCpp 第 0 章：入门与开发环境

本章不写多少代码，但决定你后面所有章节的体验：**开发流程、构建配置、编译标准**。

本教程节选 4 个最实用的主题（0.1–0.3、0.8 为背景阅读，建议直接读原文）：

| 文件夹 | 对应课程 | 主题 |
|--------|----------|------|
| [01-cpp-development](01-cpp-development/) | 0.4–0.5 | 源码→编译→链接→运行的完整流程 |
| [02-compiler-linker-libraries](02-compiler-linker-libraries/) | 0.6–0.7 | 环境、编译并运行第一个程序、读报错 |
| [03-build-configurations](03-build-configurations/) | 0.9 | Debug vs Release 构建配置 |
| [04-language-standard](04-language-standard/) | 0.11–0.13 | 语言标准、编译警告级别 |

## 学习路径

1. 读 `01-cpp-development/README.md`，理解编译/链接的分工；做它的练习（亲眼看一次链接错误）。
2. 编译运行第一个程序，练习读编译错误。
3. 用 Debug/Release 两种配置编译同一程序并比较。
4. 完成警告排查练习，养成 `-Wall -Wextra` 零警告的习惯。
