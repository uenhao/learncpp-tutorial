# 1.2 注释

📖 原文：[Comments](https://www.learncpp.com/cpp-tutorial/comments/)

## 两种注释

```cpp
// 单行注释：从 // 到行尾

/* 多行注释
   可以跨越多行 */

int x = 5; // 行尾注释也可以
```

## 最佳实践

- 注释解释**为什么**这么做，而不是复述代码**做了什么**；
- 库代码、函数顶部写注释；自解释的代码少注释；
- 不要用注释禁用大段代码——删除，交给版本控制；
- 多行注释**不能嵌套**：`/* /* */ */` 会在第一个 `*/` 结束。
