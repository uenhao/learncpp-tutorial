# 1.11 开发你的第一个程序：身高排序问题

📖 原文：[Developing your first program](https://www.learncpp.com/cpp-tutorial/developing-your-first-program/)

## 问题

> 一家小型招聘公司要按身高从高到低给候选人排序。写一个程序：读入若干人的名字与身高，输出排序结果。

## 开发步骤（原文方法论）

1. **明确需求**：输入什么？输出什么？
2. **分解问题**：读输入 → 存储 → 排序 → 输出；
3. **写伪代码**，再翻译成 C++；
4. **编译、测试**（用你手工算过的用例验证）。

本章工具箱还太小（没有数组/循环/自定义类型），所以原文用**固定数量的变量**解决 3 个人：

```
读入 name1 height1, name2 height2, name3 height3
两两比较交换（照抄三个 if）
输出
```

这正是**"问题受限于已知工具"**的典型案例——学完第 5 章（循环）和第 17 章（容器）你会回来重写它。

## 示例与练习

- 示例 `height_sort.cpp`：3 人排序的完整实现；
- 练习：扩展成 4 人排序（体会变量爆炸），并在注释里回答"哪里最难受"。
