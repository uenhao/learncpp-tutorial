# 第 1 章 小结与测验

📖 官方测验：[Chapter 1 summary and quiz](https://www.learncpp.com/cpp-tutorial/chapter-1-summary-and-quiz/)

## 本章要点

| 主题 | 要点 |
|------|------|
| 语句 | 以 `;` 结尾，顺序执行 |
| main | 程序入口，返回 0 表示成功 |
| 变量 | 类型 + 名字 + 值；定义时**总是初始化** |
| 初始化 | 优先 `{}` 列表初始化（禁止窄化） |
| iostream | `<<` 输出、`>>` 输入；优先 `'\n'` |
| UB | 未初始化局部变量是未定义行为 |
| 表达式 | 产生值；注意整数除法截断 |

## 综合测验（官方题改编）

打开 [exercises/quiz.cpp](exercises/quiz.cpp) 完成 4 道题，参考答案在 [solutions/](solutions/)。

### 题目预览

1. **找错**：一段程序含初始化/输出错误，指出并修复。
2. **预测输出**：读程序写结果（考察整数除法与运算顺序）。
3. **编写**：读入两个整数，输出它们的和、差、积、商（思考：商的类型）。
4. **编写**：模拟"购买计算器"——读入单价与数量，输出总价（只用本章知识）。

完成后：
- 编译运行验证；
- 与 [solutions/quiz.cpp](solutions/quiz.cpp) 对比；
- 回到 learncpp 官方测验页做原题。
