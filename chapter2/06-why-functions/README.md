# 2.6 为什么函数有用 & 如何高效使用

📖 原文：[Why functions are useful](https://www.learncpp.com/cpp-tutorial/why-functions-are-useful-and-how-to-use-them-effectively/)

## 函数的收益

1. **复用**：写一次，处处调用；
2. **测试/复现 bug 更容易**：可直接调用单个函数验证；
3. **抽象与可读性**：`computeInterest(...)` 比 10 行公式自解释；
4. **消除重复**：改一处即处处生效。

## 高效使用函数（原文最佳实践）

- **一个函数只做一件事**，名字说清楚这件事；
- 函数要**短**：屏幕能一屏读完为佳；
- 通过**参数**接收所需数据，而不是依赖"恰好存在"的全局变量；
- 拿不准要不要拆函数时：**拆**。函数调用开销在现代 CPU 上几乎可忽略；
- 死代码立刻删除。
