# 2.13 如何设计你的第一个程序

📖 原文：[How to design your first programs](https://www.learncpp.com/cpp-tutorial/how-to-design-your-first-programs/)

## 设计方法论（原文核心）

写代码前先回答三个问题：**输入什么 → 输出什么 → 如何从前者到后者**。

### 推荐流程

1. **需求**：用一句话说清程序做什么；
2. **分解**：按"步骤"或"名词"切分成函数（自顶向下）；
3. **伪代码**：每个函数用中文/英文短句写清逻辑；
4. **实现**：把伪代码翻译成 C++，一处一处来；
5. **测试**：正常值、边界值（0、负数、超大）、非法输入。

### 分解的两条思路

- **按步骤**（过程式）：读数据 → 处理 → 输出；
- **按名词**（为对象做铺垫）：程序里的"东西"（玩家、账户）各自成为模块。
