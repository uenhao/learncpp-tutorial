# 六步走查答案

① **根因**：`int area { width + height };` —— 症状出现在打印行，但打印的变量是 area；
   溯源到 area 的初始化，写的是加法，面积应为乘法。
② **理解**：把"面积 = 宽 × 高"误写成了"宽 + 高"。
③ **修法**：`+` 改 `*`。（备选：改成函数；本例最小改动即可。）
④ **修复**：`int area { width * height };` 编译通过。
⑤ **复测**：输出 `area = 15`，符合 3×5。
⑥ **复测无新伤**：程序只有这一个功能，无其他影响。

要点复盘：症状（打印错值）≠ 根因（初始化行）。若在打印行"修"（比如打印 area*5），
数值碰巧对了，但根因还在——换一组宽高立刻翻车。这就是"症状 ≠ 根因"的代价。
