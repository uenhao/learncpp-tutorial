第 0 章 · 入门与开发环境

这一章几乎不写代码，但它决定你后面所有章节的"手感"：代码如何变成程序？报错信息如何读？编译器按什么规则工作？

建议路线：先学 0.1（编译与链接的旅程），它给你"报错导航图"；再学 0.2（构建配置），它解释"为什么同一份代码在不同人机器上表现不同"。每节都有判断题和预测题，先自己预测，再看答案——猜错了的印象最深刻。

  • 0.1 · 编译与链接：你的代码经历了什么未开始
  • 0.2 · 构建配置与语言标准未开始
🧭 为什么先学这些？

learncpp 的作者把编译器配置放在第 0 章而不是附录，是因为初学者 80% 的"神秘问题"（代码没错却报错、别人能跑我不能跑、警告一大堆）根源都在这一章。把这章吃透，第 1 章开始你会顺畅得多。
