1.1 语句与程序结构

在接触任何语法细节之前，先建立一个执行模型：程序到底是怎么"跑"起来的？这个模型会贯穿你整个 C++ 生涯。

心智模型：CPU 是一个只向下走的阅读者

📐 概念

语句（statement）：一条让计算机做某件事的指令。C++ 里大多数语句以分号 ; 结尾——分号不是"行结束符"，而是"语句结束符"。

顺序执行：没有特殊指令时，CPU 从上到下、一条一条执行语句，绝不跳步、绝不回头。

最小的 C++ 程序长这样：

int main()
{
    return 0;
}

别小看这几行，每一部分都有名字：

  • int main() —— 函数头：声明了一个叫 main 的函数。它是特殊函数：操作系统从这里开始执行你的程序。
  • { 和 } —— 花括号：圈出函数体（function body），即"这个函数要执行的语句清单"。
  • return 0; —— 返回语句：结束 main，把 0 交回操作系统。约定俗成：0 = 成功，非零 = 出了问题。

判断"分号是 C++ 的换行符，一行末尾必须有分号。"

语句是排队执行的：先来后到，不可跳越

#include <iostream>

int main()
{
    std::cout << "First" << '\n';
    std::cout << "Second" << '\n';
    return 0;
}

输出永远是 First 换行 Second —— 语句顺序决定输出顺序

现在做一个预测练习。注意 << 是"把右边的东西送进输出流"的意思，链式书写时从左往右依次执行：

🎯 预测输出：下面的程序输出什么（三行，用空格分隔）？

int a{ 3 };
int b{ 1 };
int c{ 2 };
a = b;   // ①
b = c;   // ②
std::cout << a << ' ' << b << ' ' << c;
⚠️ 常见误区：变量交换

上面的题暴露了一个经典陷阱：想交换 a 和 b，写 a = b; b = a; 是错的——第一步就把 b 的旧值弄丢了。正确做法需要一个临时变量"记住"旧值：

int temp{ a };
a = b;
b = temp;

这个"需要记住旧值"的需求非常常见，标准库直接提供了 std::swap(a, b)。本章最后一课的身高排序程序就用到了它。

Hello world：每一行都是谁

#include <iostream>      // 预处理指令：把 iostream 库的声明拷进来

int main()
{
    std::cout << "Hello world!\n";   // 把字符串送进输出流
    return 0;
}
