1.2 对象与变量：给内存贴上名字

程序的本质是处理数据，而数据要有个地方住。这一课讲清楚"C++ 里数据住在哪、怎么称呼它"。

📐 概念

对象（object）：一块能存储值的内存。注意这个定义比日常语言的"对象"宽得多——一个 int 也是对象。

变量（variable）：有名字的对象。int x; 做了三件事：分配一块能装 int 的内存、给它起名 x、规定它只能存整数。

值（value）：对象里此刻存放的数据，读取时取出，写入时覆盖。

要素类比（酒店房间）在代码里
类型房型（单人间/双人间，决定能住谁）int
名字房间号（别人怎么找到它）x
值当前住客5

定义 = 声明 + 分配内存

int x; 是定义（definition）：它分配了内存。而声明（declaration）只是告诉编译器"有这么个名字"。变量定义同时完成声明；但反过来不成立（第 2 章讲函数时这个区别会变得非常重要）。

int x;        // 定义：内存就位，但里面的值是垃圾！（下一课细说）
x = 5;        // 赋值：把 5 装进去

int y{ 5 };   // 定义 + 初始化：创建时就装好 5（推荐写法）

作用域：名字的"可见范围"

📐 概念

作用域（scope）：名字从定义处开始，到它所在的 {} 块结束为止。出了块，这个名字就不存在了——就像人走出了房间。

int main()
{
    int outer{ 1 };        // outer 从这里可见
    {                      // 内层块开始
        int inner{ 2 };    // inner 只在内层块里可见
    }                      // inner 在这里销毁
    // std::cout << inner; // ❌ 编译错误：inner 不存在了
}

同名的情况需要特别小心。内层块可以定义一个与外层同名的新变量——这叫遮蔽（shadowing）：

int value{ 10 };
{
    int value{ 99 };       // 这是另一个对象！碰巧同名
    std::cout << value;    // 打印 99（内层优先）
}
std::cout << value;        // 打印 10（内层已销毁）

选择上面的遮蔽代码中，两个 value 是几个对象？

✅ 最佳实践
  • 变量在离使用最近的地方定义（缩小作用域 = 减少混乱）
  • 避免遮蔽：给变量起不同的名字，让 -Wshadow 保持安静
  • 同一作用域内同名变量不能定义两次（编译器会拦住你）
💭 思维转变

"变量"这个词容易让人以为名字本身就是数据。更准确的图景是：名字是标签，对象是盒子，值是盒子里的东西。赋值是"换东西"，不改标签；对象销毁是"盒子没了"，名字也随之作废。保持这个图景，第 2 章的"按值传参"、第 12 章的"引用"都会容易得多。

🎯 预测输出（用空格分隔）：

int value{ 1 };
std::cout << value << ' ';
{
    int value{ 99 };
    std::cout << value << ' ';
}
std::cout << value;
