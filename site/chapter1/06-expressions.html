1.6 字面量、运算符与表达式

前面你一直在"用" 3、+、x * y，这一课把这三个概念正式命名——命名之后你才能谈论它们的规则。

📐 概念

字面量（literal）：直接写在代码里的固定值：42、3.14、'A'、"Hello"、true。

运算符（operator）：对值进行运算的符号。二元运算符吃两个操作数（a + b），一元吃一个（-x）。

表达式（expression）：字面量、变量、运算符的组合，求值后产生一个值。2 + 3 是表达式（值 5）；单独一个变量 x 也是表达式（值是 x 当前的值）。

字面量的"长相"区分类型

42        // 整数字面量
3.14      // 浮点字面量（默认 double）
'A'       // 字符字面量 —— 单引号，恰好一个字符
"A"       // 字符串字面量 —— 双引号（哪怕只有一个字符也是字符串！）
true      // 布尔字面量

表达式求值：优先级与结合性

表达式怎么算出唯一的结果？两条规则：

  • 优先级：* / % 先于 + -（与数学一致）
  • 结合性：同级运算从左往右
2 + 3 * 4      // 14：先乘后加
10 - 4 - 3     // 3：从左往右 (10-4)-3
(2 + 3) * 4    // 20：括号优先

整数除法：初学者第一大坑

⚠️ 反例：钱去哪了
int total{ 100 };              // 100 分
int people{ 3 };
int each{ total / people };    // 33.33... → 33
std::cout << each;             // 33 —— 1 分钱神秘消失

int / int 结果还是 int，小数部分直接丢弃（向零截断，不是四舍五入）。想要 33.33，需要至少一个操作数是浮点数（第 4 章讲 double 与类型转换时彻底解决）。

与 / 配对的是取余 %：整除后的余数。7 % 2 == 1、10 % 5 == 0。它常用来判断奇偶（x % 2）、循环节（i % 7）。

📐 概念：副作用（side effect）

表达式除了"算出一个值"，还可以改变世界：x = x + 1 求值的同时修改了 x。"求值 + 修改状态"合起来叫副作用。现在只需知道这个词；到第 5 章讲 ++、函数调用时它变得至关重要。

✅ 最佳实践：拿不准就加括号

括号不改变性能（编译期就消掉了），却让意图一目了然。(a * b) + c 比让读者心算优先级更友好。可读性优先于"炫技式简洁"。

💭 思维转变：表达式是"问句"，语句是"命令"

表达式回答"这个组合的值是多少"；语句命令"去做这件事"。x + y; 作为一条语句是合法的——但它算出的值没人接住，等于白问。分清"问"与"做"，是理解后面 return x + y（把问的结果交出去）与 x == y（问相等吗）vs x = y（做赋值）这些区别的地基。

🎯 预测输出（三段，空格分隔）：

std::cout << 10 / 4 + 1 << ' ';
std::cout << 10 % 4 << ' ';
std::cout << (2 + 3) * (10 - 8);
