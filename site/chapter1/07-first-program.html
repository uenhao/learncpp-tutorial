1.7 第一个完整程序：身高排序

一章的工具已经攒够了，现在是时候用它们解决一个真实问题——并在这个过程中体会"问题如何被分解成语句"。

需求

一家招聘公司要按身高从高到低给候选人排序。写一个程序：读入若干人的名字与身高，输出排序结果。

设计：从需求到语句

learncpp 的方法论是先问三个问题：

📐 设计三问
  1. 输入是什么？—— 三组 (名字, 身高)
  2. 输出是什么？—— 同样六项，按身高降序
  3. 怎么从输入到输出？—— 读入 → 排序 → 输出

关键在第三问。"排序"听起来吓人，但我们本章没有数组、没有循环——只有变量、if 和 swap。那就人肉排序：三组数据，两两比较交换即可。先看工具，再看完整程序：

#include <iostream>
#include <string>    // std::string：存"一串字符"的类型
#include <utility>   // std::swap：交换两个对象的值

int main()
{
    std::cout << "Enter 3 names and heights (cm), e.g. Tom 180:\n";

    std::string name1{}, name2{}, name3{};
    int height1{}, height2{}, height3{};

    std::cin >> name1 >> height1 >> name2 >> height2 >> name3 >> height3;

    // 第 1 轮：把三者中最大的换到第 1 位
    if (height1 < height2) { std::swap(name1, name2); std::swap(height1, height2); }
    if (height1 < height3) { std::swap(name1, name3); std::swap(height1, height3); }
    // 第 2 轮：剩下两人中较高的换到第 2 位
    if (height2 < height3) { std::swap(name2, name3); std::swap(height2, height3); }

    std::cout << "\nSorted (tallest first):\n";
    std::cout << name1 << ' ' << height1 << '\n';
    std::cout << name2 << ' ' << height2 << '\n';
    std::cout << name3 << ' ' << height3 << '\n';
    return 0;
}

if 语句读法："如果条件为真，执行花括号里的语句，否则跳过"——第 4 章正式展开

设计中的"条件不对称"

注意排序代码的三条 if 不是机械地比较 (1,2)(2,3)(1,2)。我们换了一种写法：(1,2)(1,3)(2,3)——先把最大值"顶"到第 1 位，再处理剩下两个。两种都能正确排序，但思考路径不同：

选择用上面程序的策略，4 个人需要几次"比较"？（比较 = 一次 if 中 heightA < heightB 的判断）

⚠️ 为什么交换必须连名字一起换

只换身高不换名字，输出会变成"Tom 170 bob 180"——身高和名字对不上号。一组相关数据必须作为一个整体被移动。这个"数据要成组"的痛点，就是结构体（struct，第 15 章）诞生的原因。遇到痛点 → 记住痛点 → 以后遇到解法时你会立刻认出它。这是 learncpp 式学习法的精髓。

💭 思维转变：先设计后编码，伪代码是脚手架

注意我们写代码之前做了什么：三问 → 分解（读入/排序/输出）→ 为每一步寻找本章工具。如果某一步找不到工具（"排序 100 人"），就记录痛点而不是硬写。learncpp 作者的忠告：写程序最难的部分不是敲代码，而是在敲代码之前想清楚。伪代码（用中文短句写出每一步）永远值得先写。
