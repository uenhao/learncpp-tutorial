第 1 章 · C++ 基础

这一章构建你的 C++ 最小核心：语句怎么执行、数据住在哪里、程序怎么与人对话、表达式怎么求值。最后用一个真实问题（身高排序）把全部工具串起来。

学习方式提醒：每节的预测题先别急着看答案——预测错误的瞬间是学习效率最高的时刻。

  • 1.1 · 语句与程序结构：CPU 是个只向下走的阅读者未开始
  • 1.2 · 对象与变量：给内存贴上名字未开始
  • 1.3 · 初始化与赋值：出生与改写是两回事未开始
  • 1.4 · iostream：程序与用户的对话未开始
  • 1.5 · 关键字、命名与代码格式未开始
  • 1.6 · 字面量、运算符与表达式未开始
  • 1.7 · 第一个完整程序：身高排序未开始
  • 1.x · 章综合测验（8 题）未开始
🗺️ 本章的知识地图

如果把 C++ 比作一门语言：本章学的是单词（字面量、关键字）和简单句（语句、表达式）。第 2 章学段落（函数——把语句打包复用）。语法细节（if/循环/各种类型）从第 4 章开始陆续加入。不求一次全懂，但求本章的执行模型（1.1）和变量模型（1.2）扎实——后面一切语法都挂在这两个模型上。
