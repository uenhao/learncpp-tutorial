Part A · 概念判断

判断① 未初始化的局部变量的值，在程序多次运行时可能不同。

选择② 哪种初始化写法能阻止 double → int 的窄化转换？

判断③ std::endl 和 '\n' 完全可以互相替换。

Part B · 预测输出

④ std::cout << 7 / 2 << ' ' << 10 % 3;

⑤ 作用域与遮蔽：

int num{ 2 };
std::cout << num << ' ';
{
    int num{ 99 };
    std::cout << num << ' ';
}
std::cout << num;

⑥ 表达式 vs 副作用：

int x{ 5 };
int y{ 3 };
x = y - 2;            std::cout << x << ' ';
std::cout << (x == y) << ' ';
std::cout << y - 3;
