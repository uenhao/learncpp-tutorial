11.1 函数重载与模板

同一个 max，int 版、double 版、long 版……复制粘贴三份？C++ 的答案是重载；而"所有类型都要一份"的终极答案是模板。本章两把钥匙解锁泛型编程之门。

函数重载：同名不同参

📐 概念：函数重载（function overloading）

同一作用域内、名字相同、参数类型可区分的多个函数。编译器把它们当独立函数对待——名字冲突的担心是多余的（参数类型不同即可区分）。

int add(int x, int y)       // int 版
{
    return x + y;
}

double add(double x, double y) // double 版——合法重载
{
    return x + y;
}

int main()
{
    std::cout << add(1, 2) << '\n';     // 调 int 版：3
    std::cout << add(1.5, 2.5) << '\n'; // 调 double 版：4
    return 0;
}

重载区分规则：什么算"不同"

📐 概念：可区分 = 编译器能选出一个唯一的
  • ✅ 参数类型不同：int 版 vs double 版
  • ✅ 参数个数不同：add(int,int) vs add(int,int,int)
  • ❌ 只返回类型不同：int f() vs double f()——编译错误！
  • ❌ 只有形参名不同：f(int x) vs f(int y)——重复定义

重载解析与歧义

📐 概念：重载解析（overload resolution）

调用时编译器按实参类型挑最匹配的重载。找不到唯一最优 → 歧义 → 编译错误：

void print(int x) {}
void print(double x) {}

print(5);    // → int 版
print(5.0);  // → double 版
print('a');  // 'a' 是 char：既可提升为 int 也可转 double → 两边都"行"→ 歧义错误！
print(5L);   // long：到 int 和 double 都需转换 → 视实现可能歧义
⚠️ 最常见的歧义：字面量 0 与指针

重载 f(int) 和 f(int*) 时调用 f(0)——0 既是 int 又能当空指针 → 歧义。这也是 C++11 引入 nullptr（专用空指针类型，不产生歧义）的原因之一。

默认参数：给参数一个"保底值"

📐 概念：默认参数（default arguments）
int rollDie(int sides = 6);        // 不传就掷 6 面骰

rollDie();    // sides = 6
rollDie(20);  // sides = 20（覆盖默认）

规则：默认参数只能从右往左连续给——f(int a, int b = 2) 合法；f(int a = 1, int b) 非法（b 没默认却排在 a 后面，调用 f(5) 时不知道给谁）。

声明与定义分离时（2.11 课）：默认参数写在声明（头文件）里，定义里不重复写。

✅ 何时用默认参数（原文）
  • 参数有合理默认值，且想允许调用者覆盖——"骰子默认 6 面"；
  • 给已有函数加新参数：带默认值的新参数不破坏任何现有调用（否则所有调用点都得改）。

函数模板：一份代码，所有类型

📐 概念：函数模板（function template）

重载的尽头是复制粘贴——int 版、double 版、long 版的 max 本体一模一样。模板用占位类型（T）写一份，让编译器按需生成各版本：

template <typename T>   // T 是类型模板参数（占位）
T max(T x, T y)
{
    return (x < y) ? y : x;
}

关键认知：模板不是函数——它不直接编译执行，唯一职责是生成函数。模板 → 函数的过程叫实例化（instantiation）。

实例化：显式与隐式

std::cout << max<int>(1, 2) << '\n';    // 显式：实例化 max<int>
std::cout << max<double>(1.5, 2.5);     // 显式：max<double>
std::cout << max(3, 4) << '\n';         // 隐式：从实参推导 T=int

实例化的函数是"真实函数"——编译一次、按类型各司其职。每个用到的类型实例化一份；没用的类型不生成（不膨胀可执行文件）。

模板的坑：类型不一致

⚠️ 反例：T 推导冲突
max(3, 4.5);  // ❌ 编译错误！
// 3 推 T=int，4.5 推 T=double——一个 T 不能同时是两种

解法三选一：显式指定 max<double>(3, 4.5)（3 转 double）；用两个模板参数 template <typename T, typename U>；或调用前统一类型。

选择以下哪组不能构成合法重载？

判断"模板就是函数——写好后可以直接调用执行。"

⑩ std::cout << max(3, 4);（max 为模板，返回较大者）

💭 思维转变：重载是"接口统一"，模板是"接口的接口"

重载让调用者用同一个名字表达同一语义的不同实现——接口统一了。模板更进一步：连"不同实现"都只用写一次——把类型也参数化。回顾你的工具链进化史：字面量硬编码（1.6）→ 变量参数化（2.4）→ 函数复用（2.6）→ 模板参数化类型（本章）。每一步都是"把变化的部分抽出来交给参数"。第 16 章的 vector<int>、vector<string> 全是模板——学完本章，容器的尖括号不再是天书。
