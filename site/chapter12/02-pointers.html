12.2 指针：存地址的变量

引用是"别名"——它自己不是对象。指针（pointer）则是真正存地址的对象：有自己的内存、自己的地址，还能改变指向。它是引用的"重型兄弟"。

📐 概念：指针（pointer）

int* ptr 声明一个"指向 int 的指针"。指针存的是另一个对象的内存地址。三个核心操作：

int x{ 5 };
int* ptr{ &x };      // ① 取地址 &x，存进指针

std::cout << ptr << '\n';  // 打印地址（十六进制，如 0x7ffe...）
std::cout << *ptr << '\n'; // ② 解引用 *：取出地址处的值 → 5

*ptr = 7;                  // ③ 通过指针修改 x！
std::cout << x << '\n';    // 7

&（取地址）与 *（解引用）是一对逆操作：&x 得到地址，*ptr 从地址取值。

⚠️ & 和 * 的多义性（原文 Tip）
  • 跟在类型名后：int* ptr → 声明指针；
  • 一元表达式前：&x → 取地址；*ptr → 解引用；
  • 二元运算：x * y → 乘法。

同一个符号三种身份——判据是语境（位置）。

空指针（null pointer）：没指向任何东西的指针

📐 概念

空指针：不指向任何对象的指针。C++ 用关键字 nullptr 表示空值：

int* ptr{};          // 值初始化 → 空指针（最佳实践）
int* ptr2{ nullptr }; // 显式置空

ptr = &x;            // 之后可以再指向有效对象
⚠️ 解引用空指针/悬空指针 = UB

对空指针解引用（*ptr 当 ptr 为空时）是未定义行为——通常崩溃，但"通常"不是保证（3.1 课层级 3）。解引用前必须检查：

if (ptr)          // 指针非空时为 true（4.4 课：非零即真）
    std::cout << *ptr;

引用 vs 指针：一张表定乾坤

引用（int&）指针（int*）
本质别名（不是对象）存地址的对象（自己占内存）
必须初始化✅ 否则编译错误可后置（但建议即初始化）
能否重绑❌ 绑定后固定✅ 可随时改指向
能否为空❌ 没有空引用✅ nullptr
访问语法直接用（像普通变量）解引用 *ptr
悬挂风险有（对象销毁后悬空）有（+ 空指针 + 野指针）
✅ 选型规则（原文）
  • 能用引用就用引用——更安全（无空值）、更简洁（无解引用符号）；
  • 需要"能改变指向"或"表示不存在（空）"时才用指针——比如链表的 next、可选对象。

按地址传递（pass by address）

void printByAddress(int* ptr)
{
    if (!ptr)          // 按地址传参允许"没有对象"
        return;
    std::cout << *ptr << '\n';
}

int main()
{
    int x{ 5 };
    printByAddress(&x);   // 传地址
    printByAddress(nullptr); // 合法：表示"没有"——引用做不到
}

按地址传递让"可选参数"成为可能——调用者可以传 nullptr 表示"这项没有"。代价：函数内要解引用、要判空。**原文最佳实践：优先按引用；需要"可空/可重指向"语义时才按地址。**

预测输出什么？

int a{ 5 };
int b{ 6 };
int* ptr{ &a };
*ptr = 10;
ptr = &b;
*ptr = 20;
std::cout << a << ' ' << b;
💭 思维转变：地址成了"一等公民"

4.1 课说"每个内存地址对应 1 字节"——那时地址只是背景知识。现在地址成了可以存储、传递、解引用的一等公民。指针的本质是"把地址当数据用"，这解锁了：数据结构（链表 next）、动态内存（第 19 章）、可选语义（nullptr / std::optional）。同时它把安全责任全交给你：空指针、悬空指针、野指针三大 UB 源。**引用是"有保镖的指针"**——功能受限但安全；理解两者的机制差异，才能在正确场景选对工具。
