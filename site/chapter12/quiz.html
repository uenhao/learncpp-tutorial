第 12 章综合测验

10 题：值类别、引用三铁律、指针机制、按引用/按地址选型。先预测再作答。

判断① "字面量 5 是 lvalue。"

判断② "非 const 引用可以绑定到 const 对象。"

🎯 预测输出：

void setTo42(int& r) { r = 42; }
void trySet(int v) { v = 42; }

int main()
{
    int a{ 1 };
    int b{ 1 };
    setTo42(a);
    trySet(b);
    std::cout << a << ' ' << b;
}

判断④ "引用绑定后可以改指向别的对象——只要再赋值一次。"

判断⑤ "指针自己不占内存——它只是地址的'记号'。"

判断⑥ "解引用空指针一定会崩溃。"

选择⑦ 函数需要"可选的输出参数"（调用者可能传也可能不传），最合适的形参是？

选择⑧ 接收一个"只读的大字符串"，最佳参数类型是？

⑨ 指针重绑：

int a{ 5 };
int b{ 6 };
int* ptr{ &a };
*ptr = 10;
ptr = &b;
*ptr = 20;
std::cout << a << ' ' << b;

判断⑩ "引用比指针更安全——所以指针应该淘汰。"
