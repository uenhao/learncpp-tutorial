第 14 章综合测验

11 题：访问控制、构造函数、拷贝与转换。先预测再作答。

判断① "struct 的成员默认 public，class 的成员默认 private——这是两者在成员访问上唯一的技术差异。"

选择② class Foo { int m_x{}; int m_y{}; };（全 private），执行 Foo foo{ 6, 7 };。结果？

判断③ "Person 的成员函数 kisses(const Person& p) 里，可以直接访问参数 p 的 private 成员 p.m_name。"

选择④ const Date today{...}，成员函数 print() 未标 const。调用 today.print()？

判断⑤ "成员初始化列表支持等号写法：Foo(int x) : m_x = x { }。"

⑥ 三参构造函数想复用两参构造，在函数体里写了 Employee(name, id);（类定义沿用 14.2 课 demo：m_name{ "???" }、m_id{ 0 }）。执行后 e2.m_name 的值是？

选择⑦ 类里同时定义了 Foo() {} 和 Foo(int x = 1, int y = 2) : ...。执行 Foo foo{};？

选择⑧ Dollars(int) 已标 explicit。下列哪个能编译？

⑨ 拷贝构造函数打印 "Copy constructor called"。C++17 下执行 Something s { Something { 5 } }; 打印几次？

判断⑩ "拷贝构造函数的参数必须按引用传递——按值会无穷递归。"

判断⑪ "想让 constexpr Pair p{ 5, 6 }; 成立，Pair 的构造函数必须标 constexpr。"
