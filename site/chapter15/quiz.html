第 15 章综合测验

10 题：this 与链式、头文件组织、嵌套类型、析构与静态成员、友元。先预测再作答。

选择① 成员函数里的 this 本质上是？

选择② void add(int value) { m_value += value; } 能支撑 calc.add(5).sub(3) 这样的链式调用吗？

选择③ 类的成员函数在类外定义时，必须？

判断④ "Date.h 被 8 个 .cpp 各自包含，类定义了 8 次——违反 ODR。"

选择⑤ Type 是 Fruit 类内嵌套的非限定 enum。类外判断"是苹果"的写法？

⑥ simple1{1} 在 main 顶层、simple2{2} 在内层块（均打印构造/析构日志）。输出第 3 行是？

判断⑦ "std::exit() 会跳过所有局部对象的析构函数。"

选择⑧ static inline int s_value{ 4 }; 里 inline 的作用是？

判断⑨ "静态成员函数里可以访问非静态数据成员——只是写起来麻烦。"

判断⑩ "Display 是 Storage 的 friend——于是 Display 的 friend 也自动获得 Storage 的访问权，且 Storage 也成了 Display 的 friend。"

🏆 第 15 章全部通过！类的机关已拆解完毕——下一章：std::vector（动态数组，你亲手学过的类模板 + 嵌套类型要派上用场了）。
