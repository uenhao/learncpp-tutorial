16.1 std::vector 基础：给"一堆变量"一个容器

要存 30 个考试分数，难道定义 testScore1 到 testScore30？——1.7 课"数据要成组"的终极形态来了：本章的主角 std::vector，你亲手学过的类模板（15 章）造出的标准库动态数组。（原文 16.1–16.4）

容器（container）与数组（array）

📐 概念：container / elements / length

容器 = 为一批未命名对象（elements，元素）提供存储的类型。与 struct 的本质区别：元素没有名字——所以想装多少装多少，不必给每个元素起名。元素个数叫 length（长度）（C++ 里也常被叫 size——不幸的术语，sizeof 的 size 指字节数；本教程约定：元素个数 = length，存储量 = size）。容器是同质的（homogenous）：元素类型必须一致。

数组 = 把元素连续存储、支持快速直接访问的容器。C++ 三种主要数组：

  • C-style arrays：语言核心、源自 C，行为怪异且危险（17 章再会）；
  • std::vector：最灵活、长度可变（本章主角）；
  • std::array：C-style array 的现代替代，定长（17 章）。

判断① "容器比 struct 强在：元素没有名字，所以容器想装多少个元素都行。"

创建 vector 与下标访问

📐 概念：list constructor 与 operator[]
std::vector<int> empty{};         // 0 个元素（value initialization）
std::vector primes{ 2, 3, 5, 7, 11 }; // CTAD 推导出 vector<int>（15.2 课）
std::vector vowels{ 'a', 'e', 'i', 'o', 'u' }; // CTAD 推导出 char

std::cout << primes[0];  // 下标从 0 开始（zero-based）
primes[2] = 13;          // operator[] 返回元素的【引用】——可直接赋值

方括号里的整数叫 subscript（下标）/ index（索引）。Key insight：索引的本义是"距首元素的偏移距离"——走 0 步还在第一个元素。所以长度 5 的合法下标是 0..4，没有下标 5。⚠️ operator[] 完全不做越界检查——非法索引直接未定义行为（4 课老朋友）；越界检查靠你自己"索引前先查"。

预测② std::vector primes{ 2, 3, 5, 7, 11 };，打印 primes[0] + primes[1] + primes[2] + primes[3] + primes[4] 是多少？

⚠️ { 5 } 和 ( 5) 是两个世界：list constructor 的优先规则

容器有特殊的 list constructor（接受 initializer list：分配存储、设长度为列表元素个数、按序初始化元素）。匹配规则：initializer list 非空时，list constructor 优先于其他构造函数；列表为空时默认构造优先：

std::vector<int> v1 { 5 };  // 列表 { 5 } → list constructor → 1 个元素，值 5
std::vector<int> v2 ( 5 );  // 不是列表 → 长度构造函数 → 5 个元素，全部 0
std::vector<int> v3(365);   // 想要"365 个格子"就用直接初始化（括号）

所以给容器"非元素值"的初始化（比如长度）要用直接初始化。另外：std::vector 可以 const 但不能 constexpr（要编译期数组 → 17 章 std::array）；元素类型不能是 const（const 性由容器本身提供）。

选择③ std::vector<int> v2( 5 ); 执行后 v2.size() 和 v2[0] 是？

unsigned 长度问题：size_type 的祸根

📐 概念：size_type / size() / std::size() / std::ssize()

每个容器类定义了嵌套别名 size_type（几乎总是 std::size_t 的别名，unsigned）作为长度与索引的类型。取长度的三种方式：

std::vector prime{ 2, 3, 5, 7, 11 };

prime.size()            // 成员函数，返回 unsigned 的 size_type
std::size(prime)        // C++17 非成员函数（对容器就是调 size()）
std::ssize(prime)       // C++20！返回【有符号】大整型（通常 ptrdiff_t）

为什么要纠结？10 课的窄化规则回来了：operator[] 的形参是 unsigned 的 size_type，非 constexpr 的 signed 索引（int index{3}; prime[index]）会触发 sign conversion 警告（GCC 需显式开 -Wsign-conversion 才可见）；而 constexpr 索引可以无损转换、不算窄化（这就是为什么本章到处能用字面量做下标）。历史原因：90 年代设计者想让"下标非负 + 多一位表达力 + 一次比较做范围检查"，事后公认是错误决定——负 int 隐式转成巨大 unsigned 让非负保证失效，而 operator[] 本来就不做范围检查。现实只能接受。

判断④ "std::vector prime{2,3,5,7,11}; 执行 prime[9] 会得到编译错误。"

传递 std::vector：按 const 引用

📐 概念：pass by const reference + 函数模板

vector 按值传递会拷贝全部元素——昂贵。惯例：按 (const) 引用传。元素类型是类型的一部分，形参必须写全 const std::vector<int>&；CTAD 不能用于函数形参。想让函数接受任意元素类型的 vector：

// 方案一：函数模板（11.1 课的实战）
template <typename T>
void passByRef(const std::vector<T>& arr) { std::cout << arr[0]; }

// 方案二：C++20 缩写函数模板
void passByRef(const auto& arr) { std::cout << arr[0]; }

若函数假定"至少 4 个元素"，编译器拦不住调用者传 2 个元素的 vector → arr[3] 是 UB。对策：运行期 assert(arr.size() >= 4)（9 课）——vector 的 size() 不是 constexpr，static_assert 用不了（17 章的 std::array 可以）。更好的对策：一开始就别写依赖调用者保证长度的函数。

💭 思维转变：从"给每个值起名"到"按位置寻址"

1.7 课的身高排序曾用"名字和身高必须一起移动"的笨办法；13 课 struct 让数据成组；本课 vector 让同质数据成批——不再给每个值起名，而是给"位置"（下标）编号。下一课用循环消化"成批"：循环变量当索引，30 个分数的和只占三行。unsigned 长度的坑先记住结论：能不用整数索引就不用（16.7 课的最终答案）。
