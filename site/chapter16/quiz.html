第 16 章综合测验

10 题：创建与下标、遍历、容量与栈。先预测再作答。

选择① std::vector vowels{ 'a', 'e', 'i', 'o', 'u' };——vowels 的完整类型是？

选择② 两兄弟：std::vector<int> v1{ 5 }; 和 std::vector<int> v2( 5 );。v1 和 v2 的 size 分别是？

判断③ "std::vector prime{2,3,5,7,11}; 执行 prime[9]，编译器会报错。"

选择④ C++20 里取 vector 的有符号长度，用哪个？

判断⑤ "把 vector 传给函数时，惯例是按 const 引用——按值会拷贝全部元素。"

⑥ std::vector v{ 0, 1, 2 }; 执行 v.resize(5); 后遍历打印，输出？

判断⑦ "capacity 是 5、length 是 3 的 vector，下标 4 是合法访问。"

选择⑧ 栈式用法：预计 push 约 1000 个元素，想全程零 reallocation。开头该写？

判断⑨ "back() 返回栈顶元素并把它移除。"

判断⑩ "std::vector<bool> 是为了省空间的好优化，可放心当普通容器用。"
