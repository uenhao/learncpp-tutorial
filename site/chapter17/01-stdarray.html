17.1 std::array：把数组搬进编译期

16 章的 vector 是动态数组；本章是它的静态兄弟：std::array（定长、支持 constexpr）与 C-style arrays（17.2 课）。选 std::array 的核心理由只有一条：它能进编译期。（原文 17.1–17.6）

定长数组与常量表达式长度

📐 概念：std::array<T, N>

定长数组：长度在实例化时必须已知且不可改。std::array 有两个模板参数——元素类型 + 长度（integral non-type template argument）：

#include <array>

std::array<int, 5> a {};   // 5 个 int

constexpr int len { 8 };
std::array<int, len> b {};  // constexpr 变量也行
std::array<int, max_colors> c {};  // 枚举器也行（官方 16.9 课 count 枚举器）
  • 长度必须是常量表达式——非 const 变量、运行期常量（如函数形参 const int length）都不行；这是"长度进类型"的代价与力量；
  • 长度 0 合法（std::array<int, 0>），但访问任何元素都是 UB，用 empty() 判断；
  • std::array 是 aggregate（无构造函数，13 课）——用聚合初始化；不给初始化器时元素 default-initialized（多数未初始化！）→ 永远写 {} value-initialize；
  • CTAD（15 章老朋友）能同时推导类型和长度：constexpr std::array a1 { 9, 7, 5, 3, 1 }; → std::array<int, 5>。
✅ 最佳实践（原文）

constexpr 数组用 std::array，非 constexpr 数组用 std::vector；std::array 能 constexpr 就 constexpr（若不打算 constexpr，考虑干脆用 vector）；用 CTAD 让编译器从初始化器推导类型和长度。

判断① "std::array 的长度可以是运行期才确定的变量（比如用户输入的个数）。"

取长度与三种下标

📐 概念：size() / std::size() / std::ssize() / std::get<>
constexpr std::array prime{ 2, 3, 5, 7, 11 };

prime.size()        // 成员函数（unsigned size_type）
std::size(prime)    // C++17 非成员
std::ssize(prime)   // C++20，有符号

std::get<3>(prime)   // 编译期下标：越界 = 编译错误！
std::get<9>(prime);  // ❌ static_assert 失败（operator[] 可不会拦）
  • 长度是 constexpr——即使在非 constexpr 的数组对象上，这三个函数也返回 constexpr 值（constexpr int length{ std::size(arr) }; 合法）；
  • ⚠️ 语言缺陷：数组作为函数的 (const) 引用形参时上述性质失效（C++23 P2280 才修复）——workaround 是函数模板把长度做成模板参数 template <auto Length>；
  • 下标三法：operator[]（无检查，越界 UB——索引前自查）、at()（运行期检查，原文建议避免——要么提前查要么编译期查）、std::get<I>（编译期检查，仅限 constexpr 索引）。

选择② 想让"下标 9 越界"在编译期就被抓住，用哪个？

传参与返回：长度也是类型的一部分

📐 概念：函数模板 + static_assert 断言长度
template <typename T, std::size_t N>   // N 必须是 std::size_t，不是 int！
void passByRef(const std::array<T, N>& arr)
{
    static_assert(N != 0);  // 拒绝零长数组
    std::cout << arr[0] << '\n';
}

template <typename T, std::size_t N>
void printElement3(const std::array<T, N>& arr)
{
    static_assert(N > 3);   // 前置条件进类型系统：长度不够 = 编译错误
    std::cout << arr[3] << '\n';
}
  • 按值传参会拷贝整个数组 → 按 const 引用；元素类型+长度都得写全（CTAD 对形参无效，官方 16.4 课同款）；
  • N 必须声明为 std::size_t——模板不做转换，std::array<int, 5> 匹配不上 std::array<int, int N>；C++20 可写 auto N 让编译器推导；
  • 16 章只能运行期 assert 的"长度前置条件"，在这里升级成 static_assert（9 课的承诺兑现）；
  • 返回：std::array 不可 move（没有自己管理的数据），按值返回 = 拷贝整个数组——数组大就别按值返回；数组若不需要 constexpr，本就该用 vector（可 move）。

判断③ "函数模板里长度参数写 int 也行：template <typename T, int N> void f(const std::array<T, N>&) 能接收 std::array<int, 5>。"

类类型元素与 brace elision（花括号省略）

📐 概念：双花括号的由来

std::array 的实现本质是包着一个 C-style array 成员的 struct（T __impl[N]）。元素是类类型时不写元素类型，就得替这个内部成员补一层括号：

// ✅ 写明元素类型（brace elision 生效）+ CTAD：
constexpr std::array houses{
    House{ 13, 1, 7 }, House{ 14, 2, 5 }, House{ 15, 2, 4 } };

// ✅ 不写元素类型 → 必须双花括号（外层给 struct 成员，内层给元素）：
constexpr std::array<House, 3> houses2 {{
    { 13, 1, 7 }, { 14, 2, 5 }, { 15, 2, 4 } }};

// ❌ 单层括号又不写类型：
constexpr std::array<House, 3> bad { { 13, 1, 7 }, { 14, 2, 5 }, { 15, 2, 4 } };
// 编译器把 {13,1,7} 当成内部 C-style array 的初始化器 → 报错

Key insight：初始化 std::array 的元素为 struct/class/array 且不逐个写元素类型时，需要额外一层花括号。标量元素的单层括号（std::array<int, 5> a { 1, 2, 3, 4, 5 };）其实是 brace elision 在帮你省——等价于 {{ 1, 2, 3, 4, 5 }}。其他有 list constructor 的标准库容器（vector）没有这个问题。

选择④ std::array<House, 3> houses { {13,1,7}, {14,2,5}, {15,2,4} };（单层括号，没写 House）——结果？

引用数组不存在，枚举索引要设防

📐 概念：std::reference_wrapper 与 static_assert 设防

引用数组不存在：元素必须是可赋值的 object，引用不是（12 课三铁律）。std::array<int&, 2> 直接编译错误。想要"装引用的数组"用 std::reference_wrapper<int>（<functional>）：行为像引用，arr[1].get() = 5 改被引用对象（裸 arr[1] = 5 有歧义——改 wrapper 还是改值？），读取时隐式转换无需 get()。便捷工厂：std::ref(x) / std::cref(x)。

枚举索引的编译期设防（官方 16.9 的 static_assert 升级版）：

constexpr std::array testScores { 78, 94, 66, 77 };
static_assert(std::size(testScores) == max_students); // 编译期抓住漏加的分数！

vector 版只能运行期 assert；constexpr 数组把"枚举器与数组失配"整个推进了编译期——加枚举器忘加 initializer，编译直接失败。

💭 思维转变：长度从"数据"变成"类型"

vector 的长度是运行期数据；std::array 的长度是类型的一部分——所以长度能 static_assert、下标能编译期检查、越界能在编译期被抓住。代价是长度必须是常量表达式、不能动态伸缩。一句话选型（原文）：能 constexpr 就 std::array，否则 vector。下一课：C-style arrays——语言内置的"原始数组"，std::array 的地基。
