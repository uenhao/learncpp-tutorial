第 17 章 · 定长数组：std::array 与 C-style arrays

vector 的静态兄弟登场。std::array 把长度写进类型——错误检查、断言、遍历全部搬进编译期；C-style arrays 是语言内置的原始数组——退化（decay）、指针算术、null terminator 的老故事都在这章，也是 12 课指针的补完。（原文 17.1–17.13）

🧭 选型速查（本章最终答案）

要 constexpr → std::array；其余 → std::vector；C-style 尽量避免（官方豁免：全局 constexpr 数据）。学完本章你应该能一眼认出：sizeof 在函数内为什么撒谎（decay）、arr[0] 为什么等价 *arr（指针算术）、{ {1,2}, {3,4} } 为什么要两层括号（brace elision）。
