第 17 章综合测验

10 题：std::array 的编译期能力、decay 与指针算术、多维陷阱。先预测再作答。

选择① 哪个不能作 std::array 的长度实参？

判断② "std::get<9>(prime)（5 元素数组）是运行时抛异常，程序还能救回来。"

判断③ "函数模板 template <typename T, int N> void f(const std::array<T, N>&) 能接收 std::array<int, 5>。"

选择④ std::array<House, 3> houses { {13,1,7}, {14,2,5}, {15,2,4} };（单层括号，未写元素类型）？

选择⑤ int arr[5]{...}; auto ptr{ arr };——ptr 的类型是？

⑥ const int arr[] { 9, 8, 7, 6, 5 };，const int* ptr{ &arr[3] };。ptr[-1] 是多少？

判断⑦ "C++ 里数组就是指针——把数组传给函数就是把数组对象本身传过去。"

选择⑧ char str[255]{ "string" };——std::size(str) 和 std::strlen(str) 分别返回？

判断⑨ "在接收 C-style 数组的函数里，sizeof(arr) 返回整个数组的字节数。"

判断⑩ "全局 constexpr 程序数据（如查找表）用 C-style array 是可接受的现代用法。"
