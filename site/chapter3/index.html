第 3 章 · 调试 C++ 程序

0–2 章你见过三层报错：编译错误有报错信息、链接错误有 undefined reference——但运行时语义错误什么都不说：程序安静地给出错误答案。本章的使命就是对付这类"沉默的 bug"。

本章的知识主线：一条定位策略（hi-lo 收敛）→ 三组战术（注释/打印 → 条件编译/日志 → 调试器四件套）→ 一条预防流水线（少犯错 → 快发现 → 防回归）。所有演示都基于 VS Code（CMake Tools），配好即用。

🧰 本章需要你边读边动手

调试是肌肉记忆，不是阅读理解。3.6 起每课的练习都要求你真的按 F5、真的按 F10/F11、真的打断点——仓库 chapter3/ 里每个 demo 和 exercise 都已配好调试环境。只读不做的话，这些知识一周内就会蒸发。
