4.3 浮点数与布尔

先补一课数学：科学计数法

理解浮点数的钥匙是科学计数法——因为它决定了浮点数"哪些位数精确、哪些不精确"。

📐 概念：科学计数法与有效数字

形式：significand（尾数）× 10^exponent（指数）。C++ 里用 e 表示"×10^"：1.2e4 = 1.2×10⁴ = 12000；5e-2 = 5×10⁻² = 0.05；地球质量 5.9722e24 kg；电子质量 9.1093837e-31 kg。

有效数字（significant digits）= 尾数里的数字个数，它决定精度：3.14（3 位有效数字）vs 3.14159（6 位）——都对，但后者更精确。

三种浮点类型

类型典型尺寸典型精度（有效数字）
float4 字节约 6–9 位
double8 字节约 15–18 位
long double8/12/16 字节（平台而定）各不相同——建议避开

现代机器上 float/double 几乎总是按 IEEE 754 标准实现（可用 std::numeric_limits<double>::is_iec559 验证）。浮点类型天然有符号。

double d{ 5.0 };   // 无后缀的浮点字面量默认是 double
float  f{ 5.0f };  // f 后缀 = float
long double ld{ 5.0L }; // L 后缀
✅ 原文最佳实践
  • 默认用 double——精度高、处理快（硬件对 double 有原生优化），float 省的那点内存在现代机器上几乎无意义，还常带来精度损失
  • 浮点字面量始终带小数点（哪怕 .0）：把 5 和 5.0 区分开，一眼可辨类型
  • 避免 long double（平台差异大）

浮点的两大"坑"（现在打预防针）

⚠️ 坑一：多数浮点数无法精确存储

10 位有效数字的二进制浮点，无法精确表示所有十进制小数——就像十进制写不尽 1/3。0.1 在二进制里是无限循环小数，存进 float/double 必有舍入。推论：永远不要用 == 比较两个浮点数是否相等（比较"差值是否足够小"才是正解）；涉及钱的计算用整数"分"而不是 double"元"。

⚠️ 坑二：除以 0.0 不崩溃，而是得到特殊值

IEEE 754 规定：5.0 / 0.0 = inf（无穷），-5.0 / 0.0 = -inf，0.0 / 0.0 = NaN（Not a Number）。它们还能参与运算并继续传播——一个 inf 混进结果里可能一路扩散到最终输出。打印 inf/NaN 的字样就是它在提醒你：源头在哪需要回查。

判断"double 占 8 字节 = 64 位，所以能精确表示 0.1。"

布尔（bool）：只有真假的类型

📐 概念

布尔类型 bool：只有两个值——true 和 false。回答"是否"问题的类型。默认初始化 bool b {}; 得到 false。

反转运算符 !（逻辑 NOT）：真变假、假变真。!true == false。

bool b1 { true };
bool b2 { false };
bool b3 {};       // false
bool b4 { !true }; // false

bool 的两个真相（会影响你看程序的方式）

#include <iostream>

int main()
{
    std::cout << true << '\n';  // 打印 1
    std::cout << false << '\n'; // 打印 0
    return 0;
}
  1. bool 底层就是整数：true 存 1，false 存 0（bool 也是整型家族成员）。std::cout << b 打印的是 0/1 而不是 true/false。
  2. 想让 cout 打印 true/false？用 manipulator：
#include <iostream>

int main()
{
    std::cout << std::boolalpha; // 之后 bool 都打印 true/false
    bool up { true };
    std::cout << up << '\n';     // true
    std::cout << !up << '\n';    // false
    return 0;
}

std::boolalpha 是"字母模式"开关（alpha=字母），设一次对该流后续都生效；对应还有 std::noboolalpha 切回 0/1。

预测这段程序输出什么？

bool b { false };
std::cout << b << ' ' << !b << ' ' << (b || true);

（|| 是逻辑或——任一为真则结果为真，第 6 章细讲）

💭 思维转变：浮点"够用"的判断力 & bool 是条件的地基

浮点这一课的重点不是记参数，而是建立"这数能精确表示吗"的怀疑本能：金额→整数分；物理模拟→接受误差并用误差带比较；inf/NaN 出现→回查源头。而 bool 是下一节 if 语句的全部地基——if 做的事只是"对一个 bool 分支"。记住 true=1/false=0 这个底层事实，后面理解"任何非零值都算真"之类的行为就毫不费力。
