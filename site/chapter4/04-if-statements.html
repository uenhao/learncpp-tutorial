4.4 if 语句：程序第一次有了"想法"

到此为止，你的所有程序都是直线执行：从 main 第一行走到最后。从 if 语句开始，程序获得选择的能力——这是"控制流"的第一步（第 8 章全面展开），也是 1.7 课身高排序里我们"偷跑"的那个 if 的正式身份登记。

📐 概念

if 语句：条件为真才执行某段代码。最简形式：

if (condition)
    true_statement;

条件（condition）：求值结果为布尔值的表达式。真 → 执行；假 → 跳过。

#include <iostream>

int main()
{
    std::cout << "Enter an integer: ";
    int x {};
    std::cin >> x;

    if (x == 0)
        std::cout << "The value is zero\n";

    return 0;
}

x == 0 用的是 ==（相等比较）——求值产生 bool。对比 =（赋值）。这是 1.6 课"表达式 vs 副作用"辨析的第一个实战场景，也是最经典的初学者打字错误：if (x = 0) 会把 0 赋给 x（整个条件变成 false，且永远如此）。

else：另一条路

if (x == 0)
    std::cout << "zero\n";
else
    std::cout << "not zero\n";

条件为假时执行 else 分支。二选一，必走其一。

if 语句块与链式 else if

条件成立要执行多条语句时，用块 {}（1.1 课的花括号作用域）：

if (x > 0)
{
    std::cout << "positive\n";
    std::cout << "(greater than zero)\n";
}

多个条件排他时，else if 链从上往下检查，命中即停：

if (x > 0)
    std::cout << "positive\n";
else if (x < 0)
    std::cout << "negative\n";
else
    std::cout << "zero\n";
✅ 最佳实践：总是给 if/else 配花括号

单语句可以省略 {}，但原文强烈建议永远写上。原因：后续往分支里加语句时，忘加括号的错误（新语句游离在分支外、无条件执行）肉眼极难发现，是著名的事故来源。花括号的成本几乎为零，保险价值巨大。

逻辑运算符：组合条件

运算符名称真值条件
&&逻辑与 AND两个操作数都为 true
||逻辑或 OR至少一个为 true
!逻辑非 NOT翻转操作数
if (x > 0 && x < 10)     // x 在 (0, 10) 开区间
    std::cout << "between\n";

if (x == 0 || y == 0)    // x 或 y 至少一个是 0
    std::cout << "has zero\n";

if (!(x == 0))           // 等价于 x != 0
    std::cout << "not zero\n";
📐 概念：短路求值（short-circuit evaluation）

&& 与 || 在能确定结果时不会求值右操作数：a && b 里 a 为假则 b 根本不算（结果必假）；a || b 里 a 为真则 b 不算（结果必真）。

这不只是性能优化，更是正确性工具：if (b != 0 && a / b > 10)——左条件保证 b 非 0，右边的除法才安全。顺序反过来就是除零 UB。

真假值：任何东西都能变 bool

C++ 里整数/浮点可以直接当条件用，规则一句话：0（和 0.0）为假，其余全为真：

if (5)  // 5 非 0 → true，执行
if (0)  // 0 → false，跳过
if (-2) // 非 0 → true
⚠️ 但别把整数当 bool 写

if (n) 和 if (n != 0) 行为相同，但后者自解释——读者不用回想"n==0 是假还是真"。原文建议：条件里写明确的比较，让代码自己说话。这条规则与 1.5 课"命名要达意"一脉相承：代码是写给人读的。

找错这段代码想判断"x 等于 0"，实际会发生什么？

int x { 5 };
if (x = 0)
    std::cout << "x is zero\n";

选择if (b != 0 && a / b > 10) 里，若 b == 0，右边 a / b > 10 会被求值吗？

预测输入 10 时输出什么？

if (x > 0)
    std::cout << "A\n";
    std::cout << "B\n";   // 注意缩进！
if (x > 100)
    std::cout << "C\n";
💭 思维转变：程序开始"分流"了

if 之前，程序的执行路径唯一；if 之后，同一个程序在不同输入下走不同的路。这带来两个深远变化：① 测试变重要了——一条路径对不代表所有路径对，所以要测试每个分支（3.10 课测试函数的思想）；② 调试复杂了——hi-lo 观察要"沿实际执行的路径"做，你看到的现象取决于走了哪条分支。1.7 课身高排序的三个 if 你已经用过它们；现在你知道了它们的完整规则书。第 8 章还有 switch 和循环等着——但 if 是所有控制流的起点。
