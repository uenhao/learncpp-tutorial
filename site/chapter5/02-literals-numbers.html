5.2 字面量与进制

📐 概念：字面量（literal）

字面量：直接插入代码的值——return 5; 的 5、true、3.4、"Hello"。也叫字面量常量：含义不可重定义（5 永远是整数 5）。

字面量也有类型，由值的形式推断：整数→int；小数→double（不是 float！）；单引号→char；双引号→C 风格字符串。

后缀（suffix）：改字面量的默认类型

后缀类型示例
u / Uunsigned int5u
l / L（推荐大写）long5L
ll / LLlong long5LL
f / Ffloat5.0f
（无后缀小数）double5.0
✅ 原文最佳实践
  • 多数情况不需要后缀——除了 f（想要 float 时必须写）
  • 用大写 L 不用小写 l：小写 l 在很多字体里和数字 1 几乎一样，5l 极易误读

回顾 4.8 课你已见过的组合：double d{ 5.0 };（无后缀=double）、float f{ 5.0f };（f 后缀）、long double ld{ 5.0L };。数字分隔符也再强化一次：1'000'000（C++14，纯粹为可读性）。

进制：二进制、八进制、十六进制

📐 概念：四种进制的字面量前缀
进制前缀示例等于十进制
十进制（无）1212
二进制0b / 0B0b110012
八进制001412
十六进制0x / 0X0xC12

它们只是同一数字的不同写法——值完全相等，选用哪种取决于语境：颜色 0xFF0000（红）、位掩码 0b0000'0001、老式 Unix 权限 0755。

二进制 ↔ 十六进制：四位一组

十六进制能流行的原因：每位十六进制恰好对应 4 位二进制。

0xC  = 1100
0xFF = 1111 1111
0b1010'1100 = 0xAC

所以十六进制是二进制的"压缩记法"——16 位数据写 4 个十六进制位，比 0110100010101001 好读得多。

输出进制：dec/oct/hex 操作器

#include <iostream>

int main()
{
    int x{ 12 };
    std::cout << x << '\n';            // 12（默认十进制）
    std::cout << std::hex << x << '\n'; // c —— 切到十六进制
    std::cout << std::oct << x << '\n'; // 14 —— 切到八进制
    std::cout << std::dec << x << '\n'; // 12 —— 切回十进制
    return 0;
}

与 std::boolalpha（4.3 课）同理：一旦切换，对该流持续生效，直到再次切换。注意十六进制输出不会自动带 0x 前缀（想要前缀用 std::showbase）。

重要规则：写二进制时每 4 位加分隔符

int bin1 { 0b101101101 };       // 合法但难读
int bin2 { 0b1011'0110'1 };     // ✅ 推荐：每 4 位一组加 '
int hex1 { 0x1234ABCD };        // 十六进制同理，常用 4 位一组

预测输出什么？

int x { 0b1100 };
std::cout << x << '\n';
std::cout << std::hex << x << '\n';

💭 思维转变：进制的本质是"同一值的写法"

新手常把 0b1100、014、0xC、12 当成"四个不同的数"——错了，它们是同一个值的四种写法，就像" XII "和"12"是同一个数。选写法的标准是语境：表达"数量"用十进制；操作"比特"用二进制/十六进制（与硬件对齐）。这也呼应 4.1 课的"类型=解释规则"：进制是写法层面的事，值与类型不变。什么时候你会真正用到它们？第 O 章（位运算）里位掩码全是十六进制——现在先打好阅读基础。
