5.3 编译期求值与 constexpr

这一课回答三个递进的问题：编译器能替你提前算什么（as-if 规则）→ 什么表达式"有资格"提前算（常量表达式）→ 怎么显式要求提前算（constexpr）。它同时兑现 2.6 课的承诺：为什么"宏做常量"该被淘汰。

第一问：as-if 规则——编译器的自由度

📐 概念：as-if 规则

编译器可以随意修改你的程序——重排语句、消除冗余、提前计算——唯一约束：修改后程序的可观察行为不变。这是 Release 优化（0.2 课）的全部理论依据。

#include <iostream>

int main()
{
	int x { 3 + 4 };
	std::cout << x << '\n';
	return 0;
}

按字面执行，3 + 4 在每次运行时都要算一遍——但结果永远是 7。符合 as-if 规则的优化：编译器直接在编译期算出 7，把它当常量塞进程序。这种"编译期就把表达式算完"的做法叫编译期求值（compile-time evaluation）。

✅ 关键洞察

编译期求值让编译器替你做运行时的工作。能在编译期算完的表达式：不占运行时间、不占运行内存（结果直接嵌入指令）。这正是 0.2 课那个"Release 下变量被优化掉"现象的合法机制。

第二问：常量表达式——"有资格"的表达式

📐 概念：常量表达式（constant expression）

常量表达式：每个组成部分都能在编译期求值的表达式。允许的内容包括：

  • 字面量（5、'a'、1.2）
  • 用常量表达式初始化的 const 变量（const int x{8}; 里的 x）
  • 用常量表达式初始化的 constexpr 变量
  • 上述内容的运算组合（5 + 3、x * 2）

反例：用户输入的值、调用"普通函数"的结果——这些只能在运行时确定，不是常量表达式。

std::cin >> a;
const int b{ a };      // const，但 b 不是常量表达式（值来自运行时）
const int c{ 5 + 3 };  // const，且 c 是常量表达式（值编译期已知）
int d { c };           // d 本身不是 const，不是常量表达式
constexpr int e{ c * 2 }; // ✅ 常量表达式（下文）

第三问：constexpr——显式的编译期常量

📐 概念：constexpr 变量

constexpr：声明"这个变量必须能用常量表达式初始化"。若初始化式不是常量表达式——编译错误（而不是静默降级）。

constexpr double gravity{ 9.8 };        // ✅ 值编译期已知
constexpr int sum{ 4 + 5 };             // ✅

int a{};
std::cin >> a;
constexpr int bad{ a };                 // ❌ 编译错误！a 是运行时值

constexpr vs const：一张对照表

constconstexpr
初始化后不可改✅✅（隐含 const）
初始值可来自运行时✅❌（必须编译期已知）
是常量表达式的一部分仅当"整型且初始化式是常量表达式"✅ 总是
用途运行时常量（值来自输入/系统）编译期常量
✅ 原文最佳实践（本章核心口诀）
  • 初始值是常量表达式的常量变量 → 用 constexpr
  • 初始值不是常量表达式（运行时才确定）→ 用 const
  • 一句话：值的来源决定用哪个。"编译期知道"用 constexpr，"运行时才知道"用 const。

例外：std::string 等动态内存类型与 constexpr 不兼容（5.4 课的 string_view 是替代品）。

兑现 2.6 课的承诺：为什么宏被淘汰

#define MAX_STUDENTS 30      // 2.6 课：宏是无类型文本替换
constexpr int maxStudents{ 30 }; // 现代 C++ 的正确答案

2.6 课说"宏没有类型、没有作用域、调试困难，用 constexpr 替代"——现在你知道 constexpr 是什么了，这条最佳实践正式生效：从今天起，所有"永不变化的量"都写 constexpr 变量（值来自运行时的写 const）。

💭 思维转变：把工作从运行时搬到编译期

这一课的思维内核是一句工程哲学：能在编译期完成的工作，绝不留到运行时。constexpr 变量是这条哲学的第一块落地面（数组长度、模板参数等后续章节都会要求 constexpr）。它还改变了"常量"的角色：const 是"防守"（禁止修改），constexpr 是"进攻"（参与编译期计算）。记住选择口诀——来源决定关键字——第 5 章后面的 string（运行时构造，用 const）与 string_view（可 constexpr）还会再考你一遍。
