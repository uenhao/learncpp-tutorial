6.1 优先级、结合性与算术运算

1.6 课你用过优先级和"从左往右"，现在给它们正式的名字和完整的规则体系。

优先级（precedence）：谁先结合操作数

📐 概念

优先级：每个运算符被分配一个等级，等级高的先与操作数结合。所以 4 + 2 * 3 被分组为 4 + (2 * 3) = 10——乘除（等级 5）高于加减（等级 6）。

本课常用的等级速查（完整表见原文）：

等级运算符
1（最先）函数调用 ()、++ / --（后缀）、一元 + -、! 等
2* / %
3+ -（二元加减）
4< > <= >=
5== !=
6&&
7||
8赋值 =（条件运算符在它前面）
⚠️ 两个高频陷阱
  • 一元负号和 ！ 的等级比 == 高：!x == y 被解析成 (!x) == y（先取反再比较）——几乎从来不是你的本意。想要"x 不等于 y"要么写 x != y，要么加括号 !(x == y)。
  • == 的等级高于 && 和 ||：a || b == c 是 a || (b == c)。拿不准就加括号。

结合性（associativity）：同级怎么办

📐 概念

同级运算符按结合性分组：左结合（从左往右）——算术、比较、逻辑；右结合（从右往左）——赋值 a = b = c 等价 a = (b = c)。

7 - 4 - 1  →  (7 - 4) - 1 = 2     左结合
✅ 最佳实践

除最简单的表达式外，用括号明确分组。括号零成本、消灭记忆负担——这条在 1.6 课说过，现在你知道了完整的等级表，更应明白：优先级是"编译器的解析规则"，不是"让你背的口诀"。

一元正负号

int x{ 5 };
int neg{ -x };   // -5（一元负号：乘 -1）
int pos{ +x };   // 5（一元正号：几乎没用，只是与负号对称）

x = 5 - -3; 里两个减号身份不同：第一个是二元减法，第二个是一元负号（5 减去负 3 = 8）。一元负号紧贴操作数写（-x 不要 - x）。

除法：两个模式（1.6 课欠条再兑付）

📐 概念：除法的两种模式
  • 任一操作数是浮点 → 浮点除法，保留小数：7.0 / 4 = 1.75；
  • 两个都是整数 → 整数除法，小数部分直接丢弃（向零截断）：7 / 4 = 1，-7 / 4 = -1（注意是向零取整，不是向下取整——-1.75 截成 -1 而非 -2）。
#include <iostream>

int main()
{
    std::cout << 7 / 4 << '\n';                      // 1
    std::cout << 7.0 / 4 << '\n';                    // 1.75
    std::cout << static_cast<double>(7) / 4 << '\n'; // 1.75
    return 0;
}

预测std::cout << -7 / 4; 输出什么？

💭 思维转变：优先级表是"解析器视角"

背等级表不是目的。真正的能力是用编译器的眼睛读表达式：看到复合表达式，先按等级画括号，再看结合性，最后算值。当你发现自己需要在脑中模拟编译器分组时——就顺手把括号写进代码，让下一个读者也省一遍脑力。下一课的取模运算符还有一整个"负数签名"的惊喜等着你。
