6.3 条件运算符与逻辑运算

条件运算符 ?: —— 能嵌进表达式的 if-else

📐 概念

条件运算符（?:）：C++ 唯一的三元运算符（吃 3 个操作数），俗称"三元运算符"。它是 if-else 的表达式版本：

condition ? expression1 : expression2;
// 真 → 整个表达式取 expression1 的值；假 → 取 expression2 的值

原文示例——找最大值：

if (x > y)
    max = x;
else
    max = y;

// 等价的条件运算符写法：
max = ((x > y) ? x : y);

关键优势：它是表达式——能用在语句到不了的地方，最典型的是初始化：

int max{ (x > y) ? x : y };  // 初始化里不能写 if-else，但能写 ?:

// 打印时选择文本：
std::cout << "You are " << (age >= 18 ? "an adult" : "a minor") << '\n';
✅ 最佳实践：只在"取值"场景用 ?:

?: 适合"二选一取一个值"的场景。如果两个分支是做不同的动作（各执行多条语句），用 if-else——可读性远胜硬塞进三元的写法。别为了短而牺牲清晰。

逻辑运算符全家福（4.10 课的正式展开）

运算符形式真值条件
逻辑非 !!xx 为 false 则 true，反之亦然
逻辑与 &&x && y两者都 true 才 true
逻辑或 ||x || y至少一个 true 即 true
bool tooLarge{ x > 100 };  // 命名技巧：bool 变量名写成"陈述句"
if (!tooLarge)
    std::cout << "OK\n";

if (age >= 18 && hasID)   // 都满足才放行
    std::cout << "enter\n";

if (sick || tired || wonLottery) // 任一满足即可请假
    std::cout << "rest today\n";

NOT 的高优先级陷阱（6.1 课表格的实战）

int x{ 5 };
int y{ 7 };

if (!x > y)      // 解析为 (!x) > y → (!5)>y → 0>7 → false
    std::cout << "x is not greater\n";
else
    std::cout << "x is greater\n";   // 实际输出这句！
✅ 最佳实践

NOT 作用于其他运算符的结果时，给那部分加括号：!(x > y)。简单场景（if (!value)）不需要括号。变量命名小技巧：bool 变量写成陈述句（tooLarge、hasID），if (!tooLarge) 读起来就是一句人话。

短路求值再强化（4.4 课）

&& 左假必假 → 右边不求值；|| 左真必真 → 右边不求值。除了保住除法安全（b != 0 && a/b > 10），还能做"低成本的先遣检查"：

if (cheapCheck && expensiveCheck())  // 便宜的先算，贵的不必总跑
if (isNull || readData())            // 非空才去读

浮点比较：== / != 是雷区（4.3 课伏笔兑现）

⚠️ < > 尚可，== / != 危险
  • < > <= >=：两个数差距明显时可靠；数值几乎相等时结果随舍入误差摆动——影响不大时（游戏碰撞判定）可接受；
  • == !=：要求完全相等，而浮点几乎从不完全相等——0.1+0.2 == 0.3 是 false（4.3 课实测过）。
✅ 浮点相等的正确姿势：与"误差带"比较
double expected{ 0.3 };
double actual{ 0.1 + 0.2 };

if (actual - expected < 1e-9 && expected - actual < 1e-9)
    std::cout << "close enough\n";  // 差值在容差内视为相等

误差阈值（容差）多大取决于应用精度需求。这也是为什么 3.4/3.10 课的测试函数对浮点结果用"接近期望"而非"全等"。

预测输出什么？

int x{ 9 };
int y{ 3 };
std::cout << ((x / y == 3) ? "yes" : "no");

判断"0.1 + 0.2 == 0.3 在 double 下通常为 false，所以浮点没法做相等判断。"

💭 思维转变：表达式的能力边界

?: 的存在揭示了 C++ 的一个深层划分：语句（statement）产生动作，表达式（expression）产生值（1.6 课的问句/命令之辨）。凡是"要一个值"的位置——初始化、实参、返回值、输出链——只能放表达式；而 ?: 让"条件选择"第一次进入值的世界。逻辑运算符则把多个 bool 表达式编织成复杂条件。至此你的条件工具箱齐了：简单分支用 if，取值分支用 ?:，复合条件用 && || 组合。第 8 章的 switch 和循环会把这个工具箱扩容一倍。
