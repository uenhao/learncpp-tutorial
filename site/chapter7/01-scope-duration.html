7.1 作用域、生命周期与链接

2.5 课你学过局部作用域，还留下过两个猜想："函数怎么记住东西？""static 是什么？"。本章一次性把"名字的属性"讲完整。先立好三个正名：

📐 概念：三个属性，一个都不能少
属性管什么速记
作用域（scope）名字在哪里可见（能用）"在哪能用"
生命周期（duration）对象什么时候创建/销毁（lifetime = 存活的实际时间）"活多久"
链接性（linkage）多个文件里的同名声明是否指同一对象"跨文件吗"

回顾：块（compound statement）与局部变量

块（block，复合语句）：一对花括号括起的语句组——函数体、if 分支、循环体、裸块都是块。块结束时，块内所有对象销毁。块可以嵌套。

📐 概念：局部变量（local variable）的默认三件套
  • 块作用域：从定义点到所在块结束可见；
  • 自动生命周期（automatic duration）：定义点创建，块结束销毁；
  • 无链接性：只属于本翻译单元的本函数，别的文件看不见。

1.2 课"盒子/标签/住客"的模型 + 3.9 课的调用栈（压栈登记入住、弹栈清房）= 这三件套的完整机制。本章会往这套机制里加入两个新住客：全局变量（活到程序结束）和静态局部变量（藏在栈外的"永久房客"）。

  1. 全局变量：定义在函数外的变量——生命周期 = 整个程序；为什么非 const 的全局变量是"恶魔"（原文原话）。
  2. 影子（shadowing）：内层同名变量"遮住"外层——2.5 课见过的现象，正式分析 + 最佳实践。
  3. 链接性：internal（static）/ external（extern）——多文件程序里同名变量的规则，回收 2.4 课 ODR 的深水区。
  4. inline 变量：头文件里定义全局常量的现代解法——兑现 2.12 课"头文件保护"的后续。
  5. 静态局部变量：有记忆的局部变量——2.5 课 counter 之谜的答案。

判断① "作用域和生命周期是一回事——看不见了就是销毁了。"

判断② "局部变量有链接性 = 无链接，意思是'不能被链接器处理'。"

💭 思维转变：变量不再只有"值"，还有"档案"

从此每看到一个变量，脑中自动拉出三行档案：作用域？生命周期？链接性？这份档案决定它"在哪能用、活多久、跨不跨文件"。本章结束时你会给四种变量建档案：局部（块/自动/无）、全局（全局/静态/外）、静态局部（块/静态/无）、inline 全局常量（全局/静态/内）。档案思维是读别人代码、防命名冲突、设计多文件程序的底层能力。

💻 本课作业：为以下四个变量各写一行"档案"（作用域/生命周期/链接性）——main 里的局部变量、全局变量、static 局部变量、inline constexpr 常量。答案：块/自动/无、全局/静态/外、块/静态/无、全局/静态/内。做完再做下一节的动手练习。
