7.2 全局变量与影子

全局变量：程序级的"公共黑板"

📐 概念：全局变量（global variable）

定义在任何函数/块之外的变量。三件套档案：全局作用域（从定义点到文件尾处处可见）+ 静态生命周期（static duration）（程序启动时创建——早于 main，程序结束时销毁）+ 默认外链接（7.3 课）。

#include <iostream>

int g_x{}; // 全局变量：零初始化（4.1 课的全局零初始化保证在这里生效）

void doSomething()
{
    g_x = 3;   // 任何函数都能读写它
    std::cout << g_x << '\n';
}

int main()
{
    g_x = 5;
    doSomething();
    std::cout << g_x << '\n'; // 3 —— doSomething 的修改持久生效！
    return 0;
}

两条命名/组织惯例（原文）：前缀 g_ 或 g 标识全局（防冲突、防影子、提醒"改动会持久"）；尽量放进命名空间——命名空间里的全局变量仍是全局变量，但避免了全局命名空间污染（2.9 课的冲突规则）。

影子（shadowing）：2.5 课现象的完整分析

内层块定义与外层同名的变量 → 内层名字"遮住"外层：

#include <iostream>

int main()
{ // 外层块
    int apples{ 5 };

    { // 内层块
        std::cout << apples << '\n'; // 此时 apples 还是外层的：5

        int apples{ 0 };             // 内层新对象！从这行起遮住外层

        apples = 10;                 // 改的是内层的
        std::cout << apples << '\n'; // 10
    }                                // 内层 apples 销毁

    std::cout << apples << '\n';     // 5 —— 外层安然无恙
    return 0;
}

输出 5 10 5。2.5 课的结论"每个定义都是独立对象"没变，新增的是精确规则：从内层定义那一行起，到内层块结束，名字 apples 解析到内层对象。

影子 + 全局变量：最危险的组合

#include <iostream>

int g_x{ 5 };

int main()
{
    int g_x{ 7 };        // 局部变量遮住全局 g_x —— 名字一模一样！
    std::cout << g_x << '\n'; // 7（局部）
    std::cout << ::g_x << '\n'; // 5 —— :: 强制用全局作用域（2.9 课的作用域解析符）
    return 0;
}

::g_x 的"空命名空间前缀"明确指全局。能救急，但**正解是不制造影子**。

✅ 原文最佳实践
  • 避免定义与更外层变量同名的变量（影子是 bug 温床）；
  • 全局变量加 g_ 前缀进一步防误碰；
  • 编译器开关 -Wshadow 让编译器替你抓影子。

先尝一口"恶魔"的滋味

#include <iostream>

int g_mode{}; // 全局

void doSomething()
{
    g_mode = 2; // 任何函数都能改它
}

int main()
{
    g_mode = 1;
    doSomething();
    // 程序员以为还是 1……
    if (g_mode == 1)
        std::cout << "safe\n";
    else
        std::cout << "boom\n"; // 实际输出：doSomething 改成了 2！
    return 0;
}

预测输出什么（三行）？

int value{ 100 };

void printAndSet(int value) // 形参也叫 value！
{
    std::cout << value << '\n';
    value = 42;
}

int main()
{
    printAndSet(7);
    std::cout << value << '\n';
}
💭 思维转变：名字解析是"由内向外找最近的"

编译器解析名字的规则一句话：从当前作用域由内向外找最近的定义，找到即停。这条规则同时解释了影子的发生、::g_x 的救场、以及"为什么函数里用全局不用写前缀"。理解"找最近"之后，2.9 课命名空间的 Foo::g_x（指定在哪一层找）和本章 ::g_x（从最外层找）就统一成了一件事：名字解析的搜索路径可以被你手动指定。
