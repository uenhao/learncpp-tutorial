第 7 章综合测验

10 题：三属性、影子、链接性、inline、static 局部变量。先预测再作答。

判断① "全局变量在 main 开始执行时创建。"

选择② const 全局变量的默认链接性是？

判断③ "非 const 全局变量默认内部链接。"

预测④ 输出什么？

int x{ 5 };
int main()
{
    int x{ 10 };
    std::cout << x << ' ' << ::x;
}

选择⑤ 为什么原文称非 const 全局变量为 evil？

判断⑥ "static 局部变量的初始化只在第一次执行到时进行。"

选择⑦ 头文件里定义跨文件共享的常量，现代 C++ 的正确写法是？

判断⑧ "inline 关键字的作用是让函数运行更快。"

⑨ 以下程序输出（五行）？

void stat()
{
    static int s{ 0 };
    ++s;
    std::cout << s << ' ';
}
void auto_()
{
    int a{ 0 };
    ++a;
    std::cout << a << ' ';
}
int main() { stat(); stat(); stat(); auto_(); auto_(); }
