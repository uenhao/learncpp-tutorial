第 8 章综合测验

12 题：悬挂 else、switch、循环三型、break/continue。先预测再作答。

判断① "if/else 不写花括号，只要缩进对齐了，逻辑就不会错。"

判断② "switch 的条件可以是 std::string 或 double。"

判断③ "switch 里命中一个 case 后，执行完该 case 的语句就自动退出 switch。"

判断④ "goto 应该避免，因为它让执行路径乱成'面条'。"

预测⑤ while 循环打印什么？

int count{ 0 };
while (count < 3)
    std::cout << count << ' ';
    ++count;   // 注意缩进！

选择⑥ "先请用户输入，输入不合法就重新要"，应该用？

🎯 预测输出：

for (int i{ 0 }; i < 10; i += 3)
    std::cout << i << ' ';

判断⑧ "for (int i{0}; i < 10; ++i) 结束后，i 的值是 10，还可以继续用。"

判断⑨ "break 和 continue 都能用于循环和 switch。"

⑩ 循环结束后 sum 的值？

int sum{ 0 };
for (int i{ 1 }; i <= 5; ++i)
    sum += i;
std::cout << sum;
